# Verification Register

This is the single source of truth for claim status. Every skill checks it before using a fact. Status labels are defined in `CLAUDE.md`. `/start-here` fills this file in.

**Sources** (give each a short code and use it in the Sources column)
- `[RES]` is your resume, for example `reference/resume/<file>`.
- `[LI]` is your LinkedIn export, for example `reference/linkedin/<file>.pdf`.
- `[USER <date>]` is your answers in conversation on that date.

**Risk**
- **High:** checked in background verification or probed in interviews.
- **Med:** noticeable inconsistency.
- **Low:** cosmetic.
