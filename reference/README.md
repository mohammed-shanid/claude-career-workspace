## Subfolders

| Folder | Put here |
|---|---|
| `resume/` | Your current resume (PDF/DOCX/TEX) and newer versions |
| `linkedin/` | LinkedIn "Save to PDF" export, section screenshots, profile URL note |
| `job-descriptions/` | Target job postings. One file per posting, with a header for company, role, URL, and date saved |
| `certificates/` | Certificates, Credly or verification links, offer and experience letters |
| `projects/` | Project READMEs, papers, award certificates |

**What a LinkedIn PDF export does NOT contain:** profile photo, banner, Featured, the full Skills list, Recommendations, Activity, Open-to-Work settings, or certification credential IDs. A full audit of those sections needs screenshots in `linkedin/`.
